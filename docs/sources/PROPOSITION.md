# Sources proposées, lot 1 (1er octobre 2026)

Relecture du fichier `docs/sources/proposition.json` : 20 modules sans `source`, une page officielle reunion.fr chacun, consultée le 1er octobre 2026. Chaque extrait est recopié tel quel depuis la page (les blocs de chiffres reprennent l'encadré de la fiche : distance, type de parcours, durée, difficulté). Rien n'est encore fusionné dans `modules.json`.

Pour accepter une entrée : passer son `statut` à « valide » dans le JSON ; pour la refuser : « rejete ». La colonne « Note » signale les écarts entre la page et le module : ils ne sont pas corrigés, c'est au CEO de trancher.

Pour fusionner : passer les entrées acceptées à « valide » dans `proposition.json`, puis lancer `node scripts/merge-sources.mjs` (voir `docs/sources/LISEZMOI.md`).
